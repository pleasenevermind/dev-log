# 2026-03

## 2026-03-03

- Moved to agent security. Wrote a threat model for the tool loop: untrusted retrieved text, untrusted tool output, and model-generated code are all inputs to the next step.
- Mapped each trust boundary to a control: tool allowlist, output sanitization, sandbox for code, and an approval gate for destructive calls.

## 2026-03-04

- Prompt injection test set: 40 documents with hidden instructions, from plain 'ignore previous' to instructions inside HTML comments and CSV cells. Baseline model follows 11 of 40.

## 2026-03-05

- Indirect injection through retrieved docs is the interesting case. The model treats retrieved text as instructions even when the system prompt says not to.
- Delimiting untrusted text and labeling it 'data, not instructions' cuts success from 11 to 6. Not a fix, just friction.

## 2026-03-07

- Tool allowlist is the only control that held across every injection variant: if the tool is not exposed, the injected instruction has nothing to call. Least privilege beats prompt wording.

## 2026-03-10

- Sandboxing code execution: ran the same escape attempts in Docker, gVisor, and Firecracker. Default Docker shares the kernel and is the weakest of the three for this threat model.

## 2026-03-11

- gVisor is easy to run and blocks the syscall tricks in my list. Firecracker is stronger isolation but more setup than a dev log needs. Using gVisor for the harness.
- Mounted the workspace read-only and gave the sandbox a tmpfs. First escape attempt fails on write, which is the boring but correct outcome.

## 2026-03-12

- Network egress: default-deny, allowlist package registries. Added a DNS sinkhole log to see what the agent tries to reach. It tried metadata endpoints twice.

## 2026-03-13

- SSRF in fetch tools: block link-local, loopback, and private ranges after DNS resolution, not before. A hostname that resolves to 169.254.169.254 bypasses a naive string check.
- Redirects are the second hole. A public URL that 302s to an internal address bypasses the initial check. Disabled redirects and handle them manually.
