# 2026-03

## 2026-03-03

- Moved to agent security. Wrote a threat model for the tool loop: untrusted retrieved text, untrusted tool output, and model-generated code are all inputs to the next step.
- Mapped each trust boundary to a control: tool allowlist, output sanitization, sandbox for code, and an approval gate for destructive calls.

## 2026-03-04

- Prompt injection test set: 40 documents with hidden instructions, from plain 'ignore previous' to instructions inside HTML comments and CSV cells. Baseline model follows 11 of 40.

## 2026-03-05

- Indirect injection through retrieved docs is the interesting case. The model treats retrieved text as instructions even when the system prompt says not to.
- Delimiting untrusted text and labeling it 'data, not instructions' cuts success from 11 to 6. Not a fix, just friction.

## 2026-03-07

- Tool allowlist is the only control that held across every injection variant: if the tool is not exposed, the injected instruction has nothing to call. Least privilege beats prompt wording.
