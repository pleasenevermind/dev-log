# 2026-05

## 2026-05-05

- Instrumented the agent loop with OpenTelemetry. One trace per run, one span per model call and tool call, attributes for model, tokens, and latency.
- The first trace exposed a 12-second gap between tool calls that was not in any log. It was a retry sleeping without a span.
- Added span events for retries and validation failures. Now the trace shows why a call repeated instead of just that it did.

## 2026-05-08

- Cost per run is now a span attribute. Aggregating by task ID shows the long tail is retries, not long prompts.
- Set a sampling policy: keep every failed run, sample 10% of successes. Storage drops by 80% and debugging gets better.

## 2026-05-11

- Tried Langfuse and Phoenix on the same traces. Both handle nested spans; Phoenix's local mode is simpler for a single dev. Picked Phoenix for now.

## 2026-05-13

- Log hygiene: prompt and completion bodies are the most useful and the most dangerous. Added a redaction pass and a per-run opt-out for sensitive fixtures.
